# Unreal Engine Deep-Dive & Architecture Books

Данный репозиторий содержит сгенерированные и структурированные учебные материалы, методические руководства и технические «книги» по внутреннему устройству и архитектуре **Unreal Engine**.

## Причина создания

В связи с отсутствием официальной полнотекстовой и структурированной документации по глубоким подсистемам движка, представленные материалы были сгенерированы и систематизированы с помощью **Claude** на основе прямого анализа исходного кода Unreal Engine.

## Версионность и базис

* **Базовая версия:** Анализ и генерация стартовых материалов выполнены по актуальным исходным кодам **Unreal Engine 5.8**.
